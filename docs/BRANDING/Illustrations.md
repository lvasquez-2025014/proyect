# Illustrations — Branding

## Style Guide

- **Style**: Clean, minimal, flat vector illustrations
- **Colors**: Use brand palette (primary navy + gold accent + neutrals)
- **Theme**: Luxury, elegance, simplicity — no cartoon or childish style
- **Format**: SVG (inline preferred for interactivity)

## Use Cases

| Type | Usage | Example |
|------|-------|---------|
| Empty states | No data pages | No products yet, no orders yet |
| Onboarding | Feature explanation | First-time setup wizard |
| Error pages | 404, 500 | Page not found illustration |
| Marketing | Hero sections, feature cards | Landing page sections |
| Loading | Branded loader | App loading screen |

## Library

- **Primary**: Custom illustrations (designed for Luxury ERP)
- **Fallback**: unDraw / Humaaans (for prototyping)

## Guidelines

- Do not use stock photography
- Do not use emoji as illustrations
- Do not mix illustration styles
- Do not use illustrations in functional UI (forms, tables, dashboards)
- Every illustration should work in both light and dark mode
