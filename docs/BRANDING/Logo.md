# Logo — Branding

## Primary Logo

```
[Luxury Enterprises]
```

- **Typography**: Custom wordmark using Playfair Display (bold)
- **Color**: Gold (#C9A84C) on dark background (#1A1A2E), or Dark (#1A1A2E) on light background
- **Format**: SVG (primary), PNG @2x (fallback)

## Icon (Favicon / App Icon)

- Minimalist "LE" monogram
- Square format, transparent background
- Sizes: 16×16, 32×32, 48×48, 192×192, 512×512

## Usage Rules

- Minimum clear space: 1× logo height on all sides
- Do not stretch, skew, or rotate
- Do not change colors (use provided variants)
- Do not add effects (shadows, gradients, borders)
- Do not place on busy backgrounds without sufficient contrast

## Variants

| Variant | Usage |
|---------|-------|
| Full color (gold) | Light backgrounds |
| Full color (white) | Dark backgrounds |
| Icon only | Favicon, mobile app, small spaces |
| Monochrome | Print, one-color applications |
