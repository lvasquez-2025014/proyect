# Colors — Branding

## Brand Palette

| Token | Hex | Usage |
|-------|-----|-------|
| `--color-primary` | `#1A1A2E` | Headers, navigation, primary text |
| `--color-primary-light` | `#2D2D4A` | Hover states, secondary surfaces |
| `--color-primary-dark` | `#0F0F1A` | Footer, dark mode base |
| `--color-accent` | `#C9A84C` | CTAs, active states, highlights |
| `--color-accent-light` | `#E0C872` | Hover on gold elements |
| `--color-accent-dark` | `#A88830` | Active/pressed on gold elements |

## Neutral Palette

| Token | Hex | Usage |
|-------|-----|-------|
| `--color-bg` | `#FFFFFF` | Page background (light mode) |
| `--color-bg-secondary` | `#F8F8FA` | Card backgrounds, sections |
| `--color-bg-tertiary` | `#F0F0F3` | Input backgrounds, hover areas |
| `--color-surface` | `#FFFFFF` | Modal, dropdown, sidebar |
| `--color-border` | `#E2E2E8` | Dividers, borders |
| `--color-text` | `#1A1A2E` | Primary text |
| `--color-text-secondary` | `#6B6B80` | Secondary/label text |
| `--color-text-tertiary` | `#9E9EB0` | Placeholder, disabled |

## Semantic Palette

| Token | Hex | Usage |
|-------|-----|-------|
| `--color-success` | `#22C55E` | Positive actions, stock available |
| `--color-warning` | `#F59E0B` | Low stock, pending approval |
| `--color-error` | `#EF4444` | Errors, stock negative, overdue |
| `--color-info` | `#3B82F6` | Information, links |
