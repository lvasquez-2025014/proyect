# SEO Checklist

## On-Page SEO

- [ ] Every page has unique `<title>` (50-60 chars)
- [ ] Every page has unique `<meta name="description">` (150-160 chars)
- [ ] Heading hierarchy: H1 → H2 → H3 (never skip levels)
- [ ] Only one H1 per page
- [ ] Internal links use descriptive anchor text
- [ ] Images have descriptive file names and alt text
- [ ] URLs are descriptive, lowercase, hyphen-separated
- [ ] Canonical URL set on every page
- [ ] OpenGraph tags set (title, description, image, type, url)
- [ ] Twitter card tags set

## Technical SEO

- [ ] Sitemap.xml generated and submitted (Google Search Console)
- [ ] Robots.txt correct (disallow dashboard, api, admin)
- [ ] Pages return correct HTTP status codes (200, 404, 301)
- [ ] No broken internal links
- [ ] No duplicate content issues
- [ ] Site is mobile-friendly (responsive design)
- [ ] Page speed optimized (see performance checklist)
- [ ] HTTPS enabled
- [ ] Structured data (JSON-LD) on relevant pages (SoftwareApplication, FAQ, Article)

## Content

- [ ] Each page targets a specific keyword
- [ ] Keyword appears in: title, H1, first paragraph, URL
- [ ] Content is original and valuable (no thin content)
- [ ] Blog posts use categories and tags
- [ ] Blog posts have internal links to related content
- [ ] Blog posts have "share" buttons
- [ ] Author bio on blog posts

## International SEO

- [ ] hreflang tags for multi-language pages
- [ ] Language-specific sitemaps
- [ ] Language in URL path (`/en/`, `/es/`)
- [ ] No auto-redirect based on IP (let user choose)
- [ ] Translated content is unique (not machine-translated)

## Monitoring

- [ ] Site registered in Google Search Console
- [ ] Site registered in Google Analytics
- [ ] Core Web Vitals monitored
- [ ] 404 errors monitored and fixed
- [ ] Index coverage monitored in Search Console
- [ ] Backlinks monitored (future)
